# Encrypted market research archive

Original observations, model policies, price histories and immutable daily notes are encrypted with AES-256-GCM before they enter Git. HISTORY_KEY is a repository Actions secret, never part of this branch or the website. This is a recovery store for internal evaluation, not a public data export. Public readings and explanations are on bitcoinsidequest.com. Never force-push this branch. Retain the owner key backup; losing it makes the archive unrecoverable.
